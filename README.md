# Doom Job Research

국내 IT 기업의 **AI·백엔드** 채용공고를 모아 요약한 보드다.
[`sojw/AhnChangHo`](https://github.com/sojw) 의 `job-watcher` 가 생성해 force-push 한다.

- 요약은 **공고 원문 발췌**다. 문장을 생성하지 않는다(LLM 을 쓰지 않는다).
- 판정은 **직무명 기준**이다. 본문까지 보면 '우대사항: Kubernetes 경험' 하나로
  백엔드 공고가 인프라로 탈락한다.
- 경력 요건의 **상한**으로 거른다. 상한을 모르는 공고는 버리지 않고 `미상` 으로 표시한다.
- 같은 공고가 여러 소스에 올라오면 **회사가 직접 올린 쪽**을 남긴다.

수집처: 원티드 · 그리팅 · Greenhouse · 네이버 · 카카오 · 토스 · 오늘의집 · 현대차 · 기아

`robots.txt` 가 수집을 거부하는 곳(잡코리아, 넥슨)은 넣지 않는다.

이 리포는 산출물만 담는다. 히스토리를 쌓지 않고 매번 커밋 1개로 force-push 된다.
